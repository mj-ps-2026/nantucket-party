## 📝 Issue Tracking System

### 📌 How to Use This Folder
- Create a new `.md` file for each major task (e.g., `issue-1.md`, `issue-2.md`) 
- Format each issue with:
  ```markdown
  ## 📌 Issue Title
  
  ### 📝 Description
  
  ### 🧱 Subtasks
  - [ ] Task 1
  - [ ] Task 2
  ```
- Add labels like `feature`, `bug`, `documentation` to each file

### ✅ Example Format
```markdown
## 📌 Setup Project Structure

### 📝 Description
Create the initial folder structure and README file

### 🧱 Subtasks
- [ ] Create `/public`, `/pages`, `/components` folders
- [ ] Write `README.md` with setup instructions
- [ ] Add `.gitignore` file
```
